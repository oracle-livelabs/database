# Seer High-Tech: Oracle LiveLabs

Use Oracle AI Database to investigate component quality, trace affected
production orders, and plan a response across manufacturing plants. The workshop
combines relational SQL, JSON Relational Duality, vector search, property
graphs, spatial analysis, Oracle Machine Learning, Select AI, and Select AI
Agent.

* [Workshop introduction](introduction/introduction.md)
* [Getting Started](getting-started/getting-started.md)
* [Supporting stack and loader](stack/readme.md)

To preview the workshop, serve this directory with a local HTTP server and open
`workshops/tenancy/` or `workshops/sandbox/`. Both use Oracle's hosted LiveLabs
renderer and require network access.

All example organizations, people, orders, inspections, and locations are
synthetic. Dates use a fixed September 2026 analysis window. Costs are USD
material and setup costs; they are not sales revenue.
