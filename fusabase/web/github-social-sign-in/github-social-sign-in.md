# Add GitHub Social Sign-In

## Introduction

In this optional lab, you will add GitHub as a second social-login provider for the Recipe Share app. You will configure a GitHub OAuth App in Fusabase, add a **Sign in with GitHub** button, and use the Fusabase JavaScript SDK to open the GitHub authorization popup.

GitHub creates the OAuth App credentials, while Fusabase manages the sign-in flow and creates the Fusabase user on the first successful GitHub sign-in.

### Objectives

In this lab, you will:

- retrieve the GitHub redirect URI generated by Fusabase
- create a GitHub OAuth App
- enable GitHub social login in the Fusabase console
- add `GithubAuthProvider` and `signInWithPopup` to Recipe Share
- sign in to Recipe Share with a GitHub account

Estimated Time: 15 minutes

### Prerequisites

This lab assumes you have:

- Completed Labs 1 through 8 of this workshop.
- A GitHub account that can create an OAuth App.
- Kept Recipe Share running locally from the previous labs.

> Note: This lab changes the configuration of your Fusabase project and GitHub OAuth App. The client secret belongs only in the Fusabase console; never add it to browser code or commit it to source control.

## Task 1: Get the Fusabase redirect URI

1. Open the Fusabase console for the Recipe Share project.

2. Open **Authentication**, then open **Social login**.

    ![Configured Google provider in the Fusabase Social login page](images/social.png =85%x*)


3. Locate **GitHub** and select its action or configuration control.

4. Turn on **Enable**. Copy that URI exactly, including its path. You will register this as the GitHub OAuth App callback URL.

    ![Configured Google provider in the Fusabase Social login page](images/github.png =35%x*)


## Task 2: Create a GitHub OAuth App

1. In GitHub, open **Settings** > **Developer settings** > **OAuth Apps**, then select **New OAuth App**. You can also open that page directly with this link [GitHub OAuth Apps settings](https://github.com/settings/developers).

    ![Configured Google provider in the Fusabase Social login page](images/new-app.png =65%x*)

2. Enter a public application name, such as `RecipeShare Fusabase`.

3. Enter the URL for your Recipe Share site as the **Homepage URL**. For this workshop, use `http://localhost:8000/starter/`.

4. For the **Authorization callback URL**, paste the Fusabase redirect URI from Task 1. Do not use the local Recipe Share URL as the callback URL.
    ![Configured Google provider in the Fusabase Social login page](images/register.png =45%x*)


5. Select **Register application**. On the application page, copy the **Client ID**, then generate and copy a new **Client secret**. Keep the secret private.

    ![Configured Google provider in the Fusabase Social login page](images/keys.png =45%x*)


## Task 3: Enable GitHub in Fusabase

1. Return to the Fusabase console and open **Authentication** > **Social login** > **GitHub**.

2. Paste the GitHub OAuth App **Client ID** and **Client secret**.

3. Then select **Save**.

    ![Configured Google provider in the Fusabase Social login page](images/paste.png =35%x*)


GitHub is now available as an identity provider for your Fusabase project.

## Task 4: Add the GitHub button and Sign in through GitHub with the SDK

1. In your Recipe Share project, open `starter/index.html`.

2. In the auth popup, find the two buttons below the email and password fields:

    ```html
    <button id="signInButton" class="btn btn-primary" type="button">Sign in</button>
    <button id="signUpButton" class="btn btn-outline" type="button">Create account</button>
    ```

3. In the auth popup, add the GitHub button below:

    ```html
    <copy><button id="signInWithGoogleButton" class="btn btn-outline" type="button">Sign in with Google</button>
    <button id="signInWithGithubButton" class="btn btn-outline" type="button">Sign in with GitHub</button></copy>
    ```

    ![Configured Google provider in the Fusabase Social login page](images/code.png =100%x*)

4. Save the file.

5. Open `starter/scripts/app.js`.

2. Add `GithubAuthProvider` to the existing `fusabase/auth` import:

    ```js
    <copy>import {
      GithubAuthProvider,
      GoogleAuthProvider,
      createUserWithEmailAndPassword,
      getAuth,
      onAuthStateChanged,
      signInWithPopup,
      signInWithEmailAndPassword,
      signOut
    } from "fusabase/auth";</copy>
    ```
    ![Configured Google provider in the Fusabase Social login page](images/sdk.png =100%x*)

3. In the `el` object, add the GitHub button after `signInWithGoogleButton`:

    ```js
    <copy>signInWithGithubButton: document.querySelector("#signInWithGithubButton"),</copy>
    ```
    ![Configured Google provider in the Fusabase Social login page](images/el.png =100%x*)


4. In `bindEvents()`, add this listener after the Google sign-in listener:

    ```js
    <copy>el.signInWithGithubButton.addEventListener("click", () => {
      runAction("Signed in with GitHub.", async () => {
        await signInWithPopup(auth, new GithubAuthProvider());
      });
    });</copy>
    ```

    The Fusabase JavaScript SDK uses the class name `GithubAuthProvider` with a lowercase `h` in `hub`.

    ![Configured Google provider in the Fusabase Social login page](images/event.png =100%x*)

5. Save the file.

## Task 5: Verify GitHub sign-in

1. Refresh Recipe Share at [http://localhost:8000/starter/](http://localhost:8000/starter/).

2. If you are signed in from a previous lab, first sign out, then select **Sign in**, then select **Sign in with GitHub**.

    ![Configured Google provider in the Fusabase Social login page](images/hub.png =60%x*)


3. Complete the GitHub authorization flow in the popup.

4. When the popup closes, Recipe Share should show the GitHub account email and the **Sign out** button. The recipe and rating forms should be enabled.

    ![Configured Google provider in the Fusabase Social login page](images/hub-in.png =60%x*)


5. In the Fusabase console, open **Authentication** and confirm that a user was created for the GitHub account.

    ![Configured Google provider in the Fusabase Social login page](images/gh-proof.png =60%x*)


6. If `starter/scripts/app.js` or `starter/index.html` does not work after this lab, use `checkpoints/app-after-lab-9.js` and `checkpoints/index-after-lab-9.html` to replace the corresponding files. Keep your own `starter/fusabase-config.js`.

### Troubleshooting

- If GitHub reports a callback URL mismatch, compare the GitHub OAuth App callback URL character-for-character with the GitHub Redirect URI shown in Fusabase.
- If the Fusabase console reports that the provider is not configured, confirm that GitHub is enabled and that both client credentials were saved.
- If the popup closes without signing in, allow popups for `localhost` and retry.
- If the same email already has an account created through a different provider, the sign-in can fail because the accounts are not automatically linked. Use a new test account or remove the conflicting test user before retrying.

You have now added GitHub social sign-in to Recipe Share.
