# Workshop Details

## Short Description

Create an Oracle Cloud Infrastructure (OCI) Free Tier account and confirm that you can sign in to the OCI Console. Learn which details to prepare, how to choose a home region, and how to recognize a successful activation.

## Long Description

An OCI account gives you access to the OCI Console, where you can create and manage cloud resources. This workshop guides a new learner through the official Free Tier registration flow without creating any resources or incurring usage charges.

You will prepare the information requested during registration, create and verify the account, choose a home region deliberately, and use the activation email to reach the OCI Console. The workshop also identifies the account details to retain for later sign-in.

## Workshop Outline

1. Introduction
2. Get Started
3. Lab 1 - Prepare to Sign Up
4. Lab 2 - Create and Activate Your Account
5. Lab 3 - Sign In to OCI for the First Time

## Workshop Prerequisites

- A supported web browser and access to an email inbox.
- A mobile phone number and a payment verification method if requested during sign-up.
- Permission to create an Oracle Cloud Free Tier account for yourself or your organization.
