## Short Description

Build a Seer Lifesciences clinical supply intelligence workflow with Oracle AI Database 26ai. Learners trace dashboard, JSON, vector, graph, spatial, and Oracle Machine Learning evidence from one governed database foundation.

## Long Description

Life sciences teams need to understand quality signals, regulated product exposure, clinical supply orders, cold-chain coverage, and predictive supply risk without splitting evidence across many specialist systems. This workshop follows the Seer Lifesciences LiveStack story and shows how Oracle AI Database 26ai keeps those data types connected.

Learners use Database Actions SQL Worksheet to inspect the active schema, recreate dashboard metrics, read JSON Relational Duality documents, run AI Vector Search over regulatory and quality signal text, traverse a property graph, measure cold-chain service coverage with Oracle Spatial, and score Oracle Machine Learning models. The workshop keeps the active learner path SQL-first and deterministic.
