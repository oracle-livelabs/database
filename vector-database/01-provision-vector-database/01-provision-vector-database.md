# Lab 1: Working with the Vector Database Console

## Introduction

In this lab, you explore the Autonomous AI Vector Database Console. You retrieve the REST URL that later labs use from Python, review available embedding models, and become familiar with the console workspace.

Estimated Time: 10 minutes

### Objectives

- Retrieve the Vector Database REST URL.
- Review the available embedding models.
- Explore the Vector Database Console.

### Prerequisites

- Oracle Cloud account with rights to create Autonomous AI Vector Database resources.
- Access to the compartment and region where the workshop database will run.
