# Build Python Vector Applications with Autonomous AI Vector Database

This LiveLabs workshop recreates the original "Getting Started with AI Vector Search" flow for Autonomous AI Vector Database and a Python-first development experience.

Estimated Time: 5 minutes

The workshop keeps the original nine-lab progression and replaces SQL Worksheet and APEX-centered work with:

- Autonomous AI Vector Database provisioning and vector user setup.
- Python SDK installation and client configuration.
- Integrated embedding tables, bring-your-own-vector tables, semantic search, index management, metadata filtering, a small Python search API, and a RAG retrieval pattern.

## Workshop Flow

1. Provision an Autonomous AI Vector Database.
2. Configure a Python client.
3. Create vector tables and inspect models.
4. Create embeddings with integrated embedding.
5. Run baseline semantic search.
6. Create and compare vector indexes.
7. Use bring-your-own vectors with metadata filters.
8. Build a small Python search API.
9. Assemble a RAG retrieval flow.
