# Use Bring-Your-Own Vectors and Metadata Filters

## Introduction

The source workshop includes an image similarity search lab. This lab maps that idea to Autonomous AI Vector Database by using a bring-your-own-vector table. The sample vectors are small stand-ins for vectors that an image or multimodal embedding model would generate in a real application.

Estimated Time: X

### Objectives

- Load records with explicit dense vectors.
- Search by vector.
- Combine vector search with metadata filters.
- Connect the workflow to image or multimodal use cases.

### Prerequisites

- `park_image_vectors` table from Lab 3.

## Task 1: Load Precomputed Vectors

1. Create a file named `load_image_vectors.py`.

2. Add this code.

    ```
    <copy>
    from files.vector_client import make_client, print_items

    vecdb = make_client()

    vectors = [
        {"id": "img-001", "dense_vector": [0.92, 0.12, 0.18, 0.08], "metadata": {"park_name": "Yosemite", "region": "west", "visual": "waterfall granite cliffs"}},
        {"id": "img-002", "dense_vector": [0.10, 0.88, 0.14, 0.22], "metadata": {"park_name": "Gettysburg", "region": "east", "visual": "battlefield monument"}},
        {"id": "img-003", "dense_vector": [0.20, 0.16, 0.93, 0.11], "metadata": {"park_name": "Arches", "region": "west", "visual": "red rock arch"}},
        {"id": "img-004", "dense_vector": [0.84, 0.11, 0.20, 0.31], "metadata": {"park_name": "Olympic", "region": "west", "visual": "rainforest river"}},
        {"id": "img-005", "dense_vector": [0.12, 0.20, 0.25, 0.91], "metadata": {"park_name": "Grand Teton", "region": "west", "visual": "mountain lake"}}
    ]

    response = vecdb.upsert_vectors(
        table_name="park_image_vectors",
        vectors=vectors
    )

    print_items("Image vector upsert response", response)
    </copy>
    ```

3. Run the loader.

    ```
    <copy>
    python load_image_vectors.py
    </copy>
    ```

## Task 2: Search by Vector

1. Create a file named `search_image_vectors.py`.

2. Add a vector query.

    ```
    <copy>
    from files.vector_client import make_client

    vecdb = make_client()

    results = vecdb.query(
        table_name="park_image_vectors",
        query_by={"vector": [0.90, 0.10, 0.20, 0.10]},
        top_k=3,
        advanced_options={"distance_metric": "COSINE"}
    )

    for item in results:
        metadata = item.get("metadata", {})
        print(item.get("id"), item.get("score"), metadata.get("park_name"), metadata.get("visual"))
    </copy>
    ```

3. Run the search.

    ```
    <copy>
    python search_image_vectors.py
    </copy>
    ```

4. Confirm that records with similar visual descriptors appear first.

## Task 3: Add Metadata Filters

1. Add this filtered query to `search_image_vectors.py`.

    ```
    <copy>
    western_results = vecdb.query(
        table_name="park_image_vectors",
        query_by={"vector": [0.10, 0.18, 0.28, 0.88]},
        filters={"region": {"$eq": "west"}},
        top_k=3,
        advanced_options={"distance_metric": "COSINE"}
    )

    print("\nWestern visual search")
    for item in western_results:
        metadata = item.get("metadata", {})
        print(item.get("id"), item.get("score"), metadata.get("park_name"), metadata.get("region"))
    </copy>
    ```

2. Run the script.

    ```
    <copy>
    python search_image_vectors.py
    </copy>
    ```

3. In a production image-search app, replace the sample vectors with embeddings generated by your image or multimodal model.
