# Workshop Details

Estimated Time: 5 minutes

## Title

Build Python Vector Applications with Autonomous AI Vector Database

## Short Description

Create a Python-first vector app workflow on Oracle Autonomous AI Vector Database. Learners provision the service, configure the SDK, search sample data, tune indexes, and assemble RAG context.

## Long Description

This workshop guides AI developers and data scientists through Autonomous AI Vector Database with Python. Learners start with service access and a vector user.

They then use the `oracle-vecdb` SDK to create tables, load text and vectors, search by meaning, filter metadata, and tune indexes.

The hands-on flow keeps the same nine-lab shape as the source AI Vector Search workshop. The new labs use Python instead of SQL Worksheet and APEX.

By the end, learners have a small Python search service pattern and a RAG retrieval flow.

## Audience

AI developers and data scientists who know basic Python and want to build semantic search, RAG, or agent-memory applications on Oracle Autonomous AI Vector Database.

## Estimated Time

90 minutes

## Prerequisites

- Oracle Cloud account with permission to create Autonomous AI Vector Database resources.
- Python 3.10 or later.
- Access to an Autonomous AI Vector Database REST endpoint.
- A vector database user with REST enabled, or an OAuth bearer token.
- Ability to install Python packages with `pip`.
