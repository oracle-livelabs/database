# Create a Compute Instance

## Introduction

OCI Compute lets you provision virtual machines and bare metal servers. You can use them for apps, labs, dev environments, and administrative workloads. In this workshop, you locate the Compute service, review the instance fields, and recognize common issues.

Estimated Workshop Time: 45 minutes.

### Objectives

In this workshop, you will:

* Find the OCI Console pages used to create a Compute instance.
* Complete the required instance creation sections.
* Select an availability domain, fault domain, image, shape, network, IP assignment, SSH key, and boot volume.
* Review the instance summary before creation.
* Identify a common capacity error and find Oracle Compute FAQ resources.

### Prerequisites

* An Oracle Cloud Infrastructure tenancy.
* Permission to create Compute instances, virtual cloud networks, subnets, and related network resources in a compartment.
* An SSH public key that you can use for the instance login.
* A compartment selected for this workshop.

## Task 1: Workshop Flow

1. Start with **Lab 1** to find the Compute instance workflow in the OCI Console.
2. Continue with **Lab 2** to review each section in the instance creation page.
3. Finish with **Lab 3** to recognize the no-host-capacity error and find the Compute FAQ.
