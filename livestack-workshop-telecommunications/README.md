# SEER Telecomms LiveLabs workshop

Follow the SEER Telecomms team through subscriber support, service-order documents, plan search, activation-fraud review, network-site analysis, demand classification, and questions in plain language.

Start with the introduction and complete the labs in order. The LiveLabs sandbox prepares the workshop database before you begin.

- [Introduction](introduction/introduction.md)
- [Getting Started](getting-started/getting-started.md)
- [Tables and sample data](reference/tables-and-sample-data.md)
- [Database setup for instructors](stack/README.md)

To preview the workshop, serve this directory through a local HTTP server and open `workshops/sandbox/index.html`. The LiveLabs renderer requires network access.
